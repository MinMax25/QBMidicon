Event Filter

変換時に残す／除外するMIDIイベントの種類をチェックボックスで選択します。
チェックを入れた項目のみが変換後データに含まれます。

カテゴリ

  • Meta：メタイベント
    • MIDIチャンネルプリフィックス、著作権表示、キューポイント、デバイス名、インストゥルメント名、調の設定、歌詞、マーカー、テキスト、ポート指定、プログラム名、シーケンス番号、シーケンサ特定メタイベント、シーケンス名（曲タイトル）/トラック名、SMPTEオフセット、テンポ、拍子の設定、XF Style コード名、XF Style ガイドトラックフラグ、XF Style リハーサルマークなどの項目を個別に選択できます
  • Channel Voice：チャンネルボイスイベント
    • アフタータッチ、ノート・オフ、ノート・オン、ピッチベンド、ポリフォニックキープレッシャー、プログラムチェンジを選択できます
  • SysEx：システムエクスクルーシブイベント
    • 一般、GMシステムオフ/オン、GM2システムオン、GSリセット、GSリズムパート指定、XGシステムオンを選択できます
  • Control Change：コントロールチェンジ
    • Bank MSB、Modulation、Breath、Foot Controller、Portamento Time、Data Entry MSB、Volume、Balance、Pan、Expression をはじめとする各CC番号を個別に選択できます
チェックを外した項目は変換時に除外され、Convertedのトラック情報やEvents数にも反映されます。
