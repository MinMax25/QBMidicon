Save SMF File

変換したMIDIデータを任意のフォルダへ保存します。File メニューから開くダイアログです。

画面項目

  • Save Folder：保存先フォルダ
    • Folder Path：保存先フォルダのパスを指定します（虫眼鏡アイコンから参照可能）
  • File to be saved：保存するファイル
    • File Name Prefix：出力ファイル名の接頭辞を指定します
    • Raw Data：フィルタ適用前の生データを保存します
    • Filtered Data：Event Filter適用後のデータを保存します
    • Lyric Track Data：Synthesizer Vに取り込める形式の、歌詞付きヴォーカルMIDIを単独のファイルとして出力します
    • Lyric Text Data：歌詞テキストデータを保存します
    • Lyric SRT Data：歌詞SRT（字幕）データを保存します
  • SAVE：チェックした項目を指定フォルダへ書き出します
