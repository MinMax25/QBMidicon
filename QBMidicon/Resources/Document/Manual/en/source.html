Source

Displays the information and track list of the loaded SMF file

Screen item

  • File Info: Basic information of the loaded file
    • Path: Displays the path of the loaded file
    • Reload: Reload the file
    • Format: Displays the SMF format (Format0, etc.)
    • Track Count: Displays the number of tracks
    • Division: Displays the time base (resolution)
    • MIDI Type: Displays the type of MIDI file (XG, etc.)
  • Tab switching
    • Tracks: Track list (No / Track Name / CH / Events)
    • Tempo: Displays tempo information
    • Key: Displays key information
    • Lyric: Displays lyrics data
    • SRT: Displays subtitle (SRT) data

Tracks tab

Displays a list of each track in the loaded SMF

Item Description
No track number
Track Name Track name
CH MIDI channel
Events Number of events in the track
Select a row and right-click to display the details of the events for that track (see "Display track information details" for details).

Tempo tab

Lists tempo change events in the file

Item Description
Measure Event position (bars:beats:ticks)
Ticks Event position (absolute value in ticks)
Message Contents of tempo change (e.g. Tempo bpm=100.00)

Key tab

Displays a list of key setting events in the file

Item Description
Measure Event position (measure: beat: tick)
Ticks Event position (absolute value in ticks)
Message Key settings (e.g. KeySignature B minor)

Lyric tab

Displays lyric events in the file as text

SRT tab

Displays lyrics data as text with time code in subtitle (SRT) format

  • The number at the beginning of each block is the serial number of the subtitle.
  • The second line is the display start time --> end time (hours: minutes: seconds, milliseconds)
  • The third and subsequent lines are the lyrics text that will actually be displayed.
