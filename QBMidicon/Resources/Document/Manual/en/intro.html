Introduction

A tool for reading SMF (Standard MIDI File), filtering and converting it into a format that is easy to use in DAW

System Requirements

Operating environment is Windows OS only.

Overview

QBMidicon reads SMF files and checks the contents of tracks and events.

is a tool for removing unnecessary events, organizing track information, adjusting lyrics and SRT data, etc., and exporting it as MIDI data after conversion. The
screen consists of "Source", "Converted", "Event Filter", and
"Convert Setting", and you can perform the conversion process by checking and setting them in order from the top.
