Save SMF File

Save the converted MIDI data to any folder. This dialog opens from the File menu.

Screen item

  • Save Folder: Save destination folder
    • Folder Path: Specify the save destination folder path (can be viewed from the magnifying glass icon)
  • File to be saved: File to be saved
    • File Name Prefix: Specify the prefix of the output file name
    • Raw Data: Save the raw data before applying the filter
    • Filtered Data: Save the data after applying the Event Filter
    • Lyric Track Data: Output vocal MIDI with lyrics as a separate file in a format that can be imported into Synthesizer V
    • Lyric Text Data: Saves the lyrics text data
    • Lyric SRT Data: Saves the lyrics SRT (subtitles) data
  • SAVE: Exports the checked items to the specified folder
