installation/uninstallation procedure

Follow the steps below to install and uninstall.

  • https://github.com/MinMax25/QBMidicon/releases
  • Installation
    1. Download the latest release version ZIP file from the link above
    2. Extract the downloaded zip to any location
    3. Place QBMidicon.exe in the extracted folder to any location
    4. In v2.0.0, the settings format changes from JSON to TOML. Existing JSON settings are not migrated automatically, so configure your theme, language, and other preferences again after updating.
  • Uninstall
    • If it is no longer needed, delete the entire folder (the registry is not used)
