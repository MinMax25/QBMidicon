Event Filter

Select the type of MIDI event to keep/exclude during conversion using the checkbox.
Only checked items will be included in the converted data.

Category

  • Meta: Meta event
    • MIDI channel prefix, copyright notice, cue point, device name, instrument name, key setting, lyrics, marker, text, port specification, program name, sequence number, sequencer specific meta event, sequence name (song title)/track name, SMPTE offset, tempo, time signature setting, XF Items such as Style chord names, XF Style guide track flags, and XF Style rehearsal marks can be selected individually.
  • Channel Voice: Channel voice event
    • Aftertouch, note off, note on, pitch bend, polyphonic key pressure, program change can be selected
  • SysEx: System exclusive event
    • General, GM system off/on, GM2 system on, GS reset, GS rhythm part specification, XG system on can be selected
  • Control Change: Control change
    • Bank MSB, Modulation, Breath, Foot Controller, Portamento Time, Data Entry You can individually select each CC number including MSB, Volume, Balance, Pan, and Expression
Unchecked items will not be output by Filtering.
