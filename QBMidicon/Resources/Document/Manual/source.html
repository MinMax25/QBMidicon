読み込んだSMFファイルの情報とトラック一覧を表示します

画面項目

  • File Info：読み込んだファイルの基本情報
    • Path：読み込んだファイルのパスが表示されます
    • Reload：ファイルを再読み込みします
    • Format：SMFフォーマット（Format0など）が表示されます
    • Track Count：トラック数が表示されます
    • Division：タイムベース（分解能）が表示されます
    • MIDI Type：MIDIファイルの種別（XGなど）が表示されます
  • タブ切り替え
    • Tracks：トラック一覧（No / Track Name / CH / Events）を表示します
    • Tempo：テンポ情報を表示します
    • Key：調（キー）情報を表示します
    • Lyric：歌詞データを表示します
    • SRT：字幕（SRT）データを表示します

Tracks タブ

読み込んだSMF内の各トラックを一覧表示します

項目 説明
No トラック番号
Track Name トラック名
CH MIDIチャンネル
Events トラック内のイベント数
行を選択して右クリックすると、そのトラックのイベントを詳細表示できます（詳しくは「トラック情報詳細表示」を参照）。

Tempo タブ

ファイル内のテンポ変化イベントを一覧表示します

項目 説明
Measure イベントの位置（小節：拍：ティック）
Ticks イベントの位置（ティック単位の絶対値）
Message テンポ変化の内容（例：Tempo bpm=100.00）

Key タブ

ファイル内の調（キー）設定イベントを一覧表示します

項目 説明
Measure イベントの位置（小節：拍：ティック）
Ticks イベントの位置（ティック単位の絶対値）
Message 調の設定内容（例：KeySignature ロ短調）

Lyric タブ

ファイル内の歌詞イベントをテキスト表示します

SRT タブ

歌詞データを字幕（SRT）形式のタイムコード付きテキストとして表示します

  • 各ブロックの先頭の番号は字幕の通し番号です
  • 2行目は表示開始時刻 --> 終了時刻（時:分:秒,ミリ秒）です
  • 3行目以降が実際に表示される歌詞テキストです
