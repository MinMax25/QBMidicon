トラック情報詳細表示

SourceまたはConvertedのトラック一覧で該当行を選択し、右クリックメニューから表示できる、
トラック内の個々のMIDIイベントを一覧表示するウィンドウです。

SourceまたはConvertedの画面で対象のトラック行を選択し、右クリック→コンテキストメニューから開きます。

画面構成

エリア 項目 説明
左側：Filter / Lyric Filter Off フィルタを適用せず、トラック内の全イベントを表示します
Filter On 右側で選択したイベント種別のみを表示します
Lyric 表示モードの切り替えではなく、ファイル内に歌詞イベントがある場合にそのトラックのMIDIデータ（ノート）へ歌詞イベントを引き当てて挿入する機能です
右側：Filter（イベント種別選択） META メタイベントの表示・非表示を種別ごとに選択します
CHANNEL VOICE アフタータッチ、ノート・オン/オフ、ピッチベンドなどを選択します
SYSEX システムエクスクルーシブイベントを選択します
CONTROL CHANGE Bank MSB、Modulation、Volumeなど各コントロールチェンジを選択します

イベント一覧の項目

項目 説明
No. イベントの通し番号
Measure イベントの位置（小節：拍：ティック）
Ticks イベントの位置（ティック単位の絶対値）
CH MIDIチャンネル
Message イベントの内容（例：ControlChange BankMSB 0、NoteOn Note A2 (57) Velocity 70 など）
この画面のフィルタ設定は表示上の絞り込みのみで、Event Filter（変換設定）には影響しません。実際に変換結果から除外したい場合はEvent Filterページの設定を変更してください。
